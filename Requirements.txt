SYSTEM ARCHITECTURE REQUIREMENTS :-

Backend (Flask Server)
Port: 5000 (default Flask port)

Database: SQLite (local file - potholes.db)

API Endpoints:

GET /api/potholes (fetch all detections)

POST /api/potholes (add new detection)

Optional: DELETE /api/potholes/{id} (remove detection)

Frontend (Web Page)
Single HTML file (index.html)

Map display: 600-800 pixels height

Map center: Bengaluru (12.9716° N, 77.5946° E)

Map zoom: 12-14 (city level)

Database Schema
Table name: potholes

Fields:

id (primary key, auto-increment)

latitude (decimal number)

longitude (decimal number)

damage_type (text)

severity (text: High, Medium, Low)

confidence (decimal: 0.0 to 1.0)

image_path (text: filename)

timestamp (date and time)
